
    - SortableItem displays: thumbnail (img tag with object-cover, 120x120 rounded), item name below, type badge (small pill), remove button (X icon, top-right corner on hover)
    - For images: use item.thumbnailUrl || item.url as src
    - For video/audio: show a placeholder icon (videocam / music_note)
    - onDragEnd handler: use arrayMove to compute new order, call onReorder with new ID array
    - Grid layout: CSS grid, 4 columns on lg, 3 on md, 2 on sm (gap-3)
    - Empty state: centered text "No assets yet. Upload or add assets to get started." in text-[#555]
