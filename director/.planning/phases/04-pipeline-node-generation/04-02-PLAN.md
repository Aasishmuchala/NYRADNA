**Step 2:** Create `src/components/pipeline/SegmentNode.tsx` -- a custom ReactFlow node component:

- Receives `data` prop containing: `{ node: PipelineNode }` (the full PipelineNode object)
- Displays:
  - Asset thumbnail (64x64 rounded-lg) or a placeholder icon if no thumbnailUrl
  - Node title (text-sm font-bold text-white, truncated to 1 line)
  - Status badge: colored dot + text label using the project's color scheme:
    - pending: gray (#555)
    - ready: green (#4cb150)
    - generating: purple with pulse animation (#9c27b0)
    - completed: green (#4cb150) with checkmark
    - error: red (#d32f2f)
  - Narrative context: emotionalTone displayed as a subtle tag below the title (text-xs text-[#adaaaa])
  - Duration hint (text-xs text-[#555])
- Has a Handle on the left (target) and right (source) for edge connections, using @xyflow/react Handle component
- Card styling: bg-[#1a1a1a] border border-[#333] rounded-xl p-3, min-width 200px
- Selected state: border-[#ff9064] when `selected` prop is true

**Step 3:** Create `src/components/pipeline/PipelineCanvas.tsx`:

- Props: `{ nodes: PipelineNode[], onNodeSelect: (nodeId: string) => void, selectedNodeId: string | null }`
- Converts PipelineNode[] to ReactFlow nodes and edges:
  - Each PipelineNode becomes a ReactFlow node at position: `{ x: index * 280, y: 100 }` (horizontal layout, 280px spacing)
  - Each consecutive pair of nodes creates a ReactFlow edge (id: `e-{prev.id}-{curr.id}`, source: prev.id, target: curr.id)
  - Edge style: stroke '#555', strokeWidth 2, type 'smoothstep', animated true for 'generating' status on target node
- Registers 'segmentNode' as custom nodeType mapping to SegmentNode component
- Uses `<ReactFlow>` with fitView, nodeTypes, proOptions={{ hideAttribution: true }}
- Background: `<Background variant="dots" color="#333" gap={24} />`
- If nodes array is empty, show centered message: "No pipeline nodes yet. Generate from an asset set to get started." with icon 'account_tree' in muted style
