Create `supabase/migrations/003_pipeline_nodes.sql`:

```sql
CREATE TABLE IF NOT EXISTS pipeline_nodes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  project_id UUID NOT NULL,
  asset_set_id UUID NOT NULL REFERENCES asset_sets(id) ON DELETE CASCADE,
  asset_item_id UUID NOT NULL REFERENCES asset_set_items(id) ON DELETE CASCADE,
  position INTEGER NOT NULL DEFAULT 0,
  title TEXT NOT NULL DEFAULT '',
  description TEXT NOT NULL DEFAULT '',
  status TEXT NOT NULL DEFAULT 'pending' CHECK (status IN ('pending', 'ready', 'generating', 'completed', 'error')),
  narrative_context JSONB NOT NULL DEFAULT '{}',
  thumbnail_url TEXT,
  metadata JSONB NOT NULL DEFAULT '{}',
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_pipeline_nodes_project ON pipeline_nodes(project_id);
CREATE INDEX idx_pipeline_nodes_asset_set ON pipeline_nodes(asset_set_id);
CREATE INDEX idx_pipeline_nodes_position ON pipeline_nodes(asset_set_id, position);
```

```typescript
interface PipelineNodeState {
  nodes: PipelineNode[];
  loading: boolean;
  saving: boolean;
  generating: boolean;

  // Queries
  getNodesByAssetSet: (assetSetId: string) => PipelineNode[];

  // CRUD
  loadNodes: (projectId: string, assetSetId: string) => Promise<void>;
  addNode: (node: NewPipelineNode) => Promise<PipelineNode | null>;
  removeNode: (nodeId: string) => Promise<void>;
  reorderNodes: (assetSetId: string, nodeIds: string[]) => Promise<void>;
  updateNodeStatus: (nodeId: string, status: NodeStatus) => void;

  // Generation
  generateFromAssetSet: (projectId: string, assetSetId: string) => Promise<void>;
}
```

- `loadNodes`: GET /api/pipeline-nodes?projectId=X&assetSetId=Y
- `addNode`: POST /api/pipeline-nodes with NewPipelineNode body
- `removeNode`: DELETE /api/pipeline-nodes?id=X
- `reorderNodes`: PUT /api/pipeline-nodes?assetSetId=X with { nodeIds: string[] } body
- `generateFromAssetSet`: POST /api/pipeline-nodes/generate with { projectId, assetSetId } body, replaces nodes array on success
- `updateNodeStatus`: local-only state mutation (no API call)
- All async actions follow try/catch + set loading/saving/generating pattern from asset-set-store

Create `src/app/api/pipeline-nodes/route.ts`:

- Copy the `createServerSupabase()` helper from `src/app/api/asset-sets/route.ts`
- `mapRowToNode()`: Map snake_case DB columns to camelCase PipelineNode. Parse `narrative_context` from JSONB. Map `asset_item_id` to `assetItemId`, etc.
- GET: Requires `projectId` and `assetSetId` query params. Select from `pipeline_nodes` WHERE project_id AND asset_set_id, ORDER BY position ASC. Return PipelineNode[].
- POST: Insert a single pipeline_node from request body. Map camelCase to snake_case for insert. Return 201 with created node.
- PUT: Reorder -- accepts `{ nodeIds: string[] }` and `assetSetId` query param. For each nodeId at index i, UPDATE position = i. Return { success: true }.
- DELETE: Requires `id` query param. Delete the row. Return { success: true }.

Create `src/app/api/pipeline-nodes/generate/route.ts`:

- POST handler accepting `{ projectId, assetSetId }` in body.
- Step 1: Fetch asset set items from `asset_set_items` WHERE asset_set_id, ORDER BY position ASC.
- Step 2: Fetch the Director's Brief from `director_cuts` WHERE project_id, take the first row.
- Step 3: If brief has narrative beats, map each asset item to a node using the corresponding beat (by position index). If the brief has more beats than items, use only up to N items. If fewer beats than items, fill remaining nodes with defaults (title = item name, description = "", emotionalTone = "neutral", transitionFromPrevious = "cut", durationHint = "3-5 seconds").
- Step 4: Delete existing pipeline_nodes for this asset_set_id (clean regeneration).
- Step 5: Batch insert all new nodes with position = item index. Each node gets: title from beat.label (fallback: item.name), description from beat visual info or empty, narrativeContext from beat emotion/transition, thumbnailUrl from item.thumbnail_url or item.url, status = "pending".
- Step 6: Return the created PipelineNode[] array.
- If no asset items found, return 400 with `{ error: "Asset set has no items" }`.
- If no brief found, return 400 with `{ error: "No Director's Brief found for this project" }`.

IMPORTANT: The brief is stored in `director_cuts` table (from Phase 2 migration 001). The brief columns include `storyline JSONB`, `visual_style JSONB`, `narrative_beats JSONB`. Parse narrative_beats.beats array for mapping.
