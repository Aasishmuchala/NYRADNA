**Heuristic validation** (analyzeSequenceHeuristic function):
Iterate the full node sequence and detect these issue types:

Visual style issues (NAR-02 "visual style"):
- If a node's metadata.source === 'gap-fill' and its position is between two non-bridge nodes, flag as 'visual-style' severity 'minor' with title "Bridge scene may not match surrounding style" and suggestion "Review bridge scene visual consistency or regenerate"
- If 3+ consecutive nodes share identical emotionalTone, flag the middle one(s) as 'visual-style' severity 'minor' with title "Visual monotony in sequence" and suggestion "Consider varying the visual approach for this segment"

Pacing issues (NAR-02 "pacing"):
- If total nodes > 5 and there are no transition keywords (dissolve, fade, crossfade, wipe, morph) across the entire sequence, flag the midpoint node as 'pacing' severity 'moderate' with title "No pacing variation across sequence" and suggestion "Add transition variety to improve rhythm"
- If any node's durationHint contains "10+" or "long", flag it as 'pacing' severity 'minor' with title "Potentially long segment may disrupt flow" and suggestion "Consider splitting into shorter segments"

Story flow issues (NAR-02 "story flow"):
- If the first node has transitionFromPrevious set (it shouldn't -- it's the opening), flag as 'story-flow' severity 'minor' with title "Opening node has unnecessary transition reference" and suggestion "Remove transition context from opening segment"
- If consecutive nodes have sharply contrasting emotionalTone (e.g., one contains 'joy'/'happy'/'uplifting' and the next contains 'dark'/'somber'/'tragic') without a transition keyword, flag the second node as 'story-flow' severity 'critical' with title "Jarring emotional shift without transition" and suggestion "Add a bridge segment or soften the transition"
- If the last node's emotionalTone does not reference any conclusive keywords (resolution, calm, triumph, peace, closure, final, end), flag as 'story-flow' severity 'minor' with title "Sequence ending may lack resolution" and suggestion "Consider adjusting the final segment's tone for narrative closure"

Define tone contrast pairs: [['joy','dark'],['happy','somber'],['uplifting','tragic'],['energetic','melancholic'],['bright','gloomy']] -- check if nodeA tone contains any word from one side and nodeB tone contains the paired word.
