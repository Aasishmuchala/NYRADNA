export type GapType = 'visual' | 'narrative';
export type GapSeverity = 'critical' | 'moderate' | 'minor';
export type GapStatus = 'detected' | 'accepted' | 'dismissed' | 'fill-requested';

export interface PipelineGap {
  id: string;
  projectId: string;
  assetSetId: string;
  sourceNodeId: string;      // FK to pipeline_nodes.id (left node in the pair)
  targetNodeId: string;      // FK to pipeline_nodes.id (right node in the pair)
  gapType: GapType;
  severity: GapSeverity;
  status: GapStatus;
  title: string;             // e.g., "Visual discontinuity between Node 2 and Node 3"
  description: string;       // detailed explanation of what was detected
  suggestion: string;        // recommended fix (e.g., "Add a dissolve transition scene")
  metadata: Record<string, unknown>; // flexible JSONB for analysis details
  createdAt: string;
  updatedAt: string;
}

export interface NewPipelineGap {

  sourceNodeId: string;
  targetNodeId: string;
  gapType: GapType;

  title: string;
  description: string;
  suggestion: string;
  metadata?: Record<string, unknown>;
}

**1. Create `src/lib/stores/gap-store.ts`** following the pipeline-node-store.ts pattern exactly:

Zustand store `useGapStore` with state:
- `gaps: PipelineGap[]` (all gaps for current context)
- `loading: boolean`
- `analyzing: boolean`

Actions:
- `loadGaps(projectId: string, assetSetId: string): Promise<void>` - GET /api/pipeline-gaps?projectId=X&assetSetId=Y, sets gaps array
- `analyzeGaps(projectId: string, assetSetId: string): Promise<void>` - POST /api/pipeline-gaps/analyze with {projectId, assetSetId}, sets analyzing=true during call, replaces gaps array with result
- `updateGapStatus(gapId: string, status: GapStatus): Promise<void>` - PUT /api/pipeline-gaps?id=gapId with {status}, updates local gap on success
- `dismissGap(gapId: string): Promise<void>` - calls updateGapStatus(gapId, 'dismissed')
- `acceptGap(gapId: string): Promise<void>` - calls updateGapStatus(gapId, 'accepted')
- `requestFill(gapId: string): Promise<void>` - calls updateGapStatus(gapId, 'fill-requested')
- `getGapsByEdge(sourceNodeId: string, targetNodeId: string): PipelineGap[]` - filter gaps by node pair

**2. Create `src/app/api/pipeline-gaps/route.ts`** following the pipeline-nodes/route.ts pattern:

- `mapRowToGap(row)` function: snake_case DB columns to camelCase PipelineGap (same pattern as mapRowToNode)
- `createServerSupabase()` using the exact same cookies pattern from pipeline-nodes
- `GET`: requires projectId + assetSetId query params, returns all gaps ordered by source_node_id position
- `PUT`: requires id query param + {status} body, updates status + updated_at, returns updated gap
- `DELETE`: requires id query param, deletes gap, returns {success: true}

**3. Create `src/app/api/pipeline-gaps/analyze/route.ts`** following the dual-mode pattern from briefs/analyze:

POST handler accepting {projectId, assetSetId}:

Step 1: Fetch pipeline_nodes for the asset set ordered by position
Step 2: Fetch the director_cuts brief for the project (same as generate route)
Step 3: Delete existing pipeline_gaps for this asset set (clean re-analysis, same as clean regeneration pattern)
Step 4: For each adjacent node pair (i, i+1), run gap analysis:

**Heuristic gap analysis (deterministic mock, default mode when no OPENAI_API_KEY):**
For each adjacent pair of nodes, check:

- **Narrative gap detection (GAP-03):**
  - If node[i].narrativeContext.transitionFromPrevious is null or 'cut' AND node[i+1].narrativeContext.emotionalTone differs significantly from node[i].narrativeContext.emotionalTone: severity='moderate', type='narrative', description="Abrupt emotional shift from '{toneA}' to '{toneB}' with hard cut transition"
  - If two adjacent nodes have identical emotionalTone: severity='minor', type='narrative', description="Repetitive emotional tone '{tone}' across consecutive segments may reduce engagement"
  - If the pair crosses the midpoint of the sequence (position around length/2) and there is no transition keyword in transitionFromPrevious: severity='critical', type='narrative', description="Missing narrative pivot at sequence midpoint between '{titleA}' and '{titleB}'"

- **Visual gap detection (GAP-02):**
  - If node[i].thumbnailUrl exists and node[i+1].thumbnailUrl is null (or vice versa): severity='moderate', type='visual', description="Visual reference missing for '{title}' — cannot assess continuity"
  - If both nodes have thumbnailUrl but different asset items (always true in generated pipelines): severity='minor', type='visual', description="Visual continuity check needed between '{titleA}' and '{titleB}' — different source assets"

For each detected gap, generate a suggestion string:
- narrative gaps: "Consider adding a bridge scene with '{transitionType}' transition to smooth the emotional shift"
- visual gaps with missing thumbnail: "Upload a reference image for '{title}' to enable visual continuity analysis"
- visual continuity: "Review color palette and composition between these segments for consistency"

**AI-powered analysis (when OPENAI_API_KEY is set):**
Use the same direct fetch to OpenAI pattern from briefs/analyze. System prompt asks the model to analyze adjacent pipeline node pairs for narrative and visual gaps. Input: the full node list + brief context. Output: JSON array of gaps with type, severity, title, description, suggestion. Fall back to heuristic on failure.

Step 5: Batch insert all detected gaps into pipeline_gaps table
Step 6: Return the inserted gaps as PipelineGap[] sorted by source node position

Each gap row uses: project_id, asset_set_id, source_node_id=nodes[i].id, target_node_id=nodes[i+1].id, plus the detected gap_type, severity, title, description, suggestion, metadata={analysisMethod: 'heuristic'|'ai'}.
