**1. Create `src/components/pipeline/GapMarker.tsx`:**

A component rendered as an edge label on ReactFlow edges where gaps exist. It receives gaps for that edge and shows a clickable indicator.

Props:
```typescript
interface GapMarkerProps {
  gaps: PipelineGap[];
  onClick: () => void;
}
```

Rendering:
- Small circular badge positioned on the edge midpoint (rendered as edge label via ReactFlow's `label` prop or `EdgeLabelRenderer`)
- Badge shows gap count if multiple gaps on one edge (e.g., "2")
- Badge shows single icon if one gap: material-symbols-outlined "warning" for narrative, "palette" for visual
- Color coding by HIGHEST severity among the gaps on that edge:
  - critical: `bg-red-500/20 border-red-500 text-red-400` (red theme)
  - moderate: `bg-amber-500/20 border-amber-500 text-amber-400` (amber theme)
  - minor: `bg-[#555]/20 border-[#555] text-[#adaaaa]` (muted, matches project's gray)
- Hover: slight scale-up (`hover:scale-110 transition-transform`)
- onClick calls the onClick prop to select this edge's gaps in the detail panel
- 'use client' directive at top
- Export as default with memo() wrapper
